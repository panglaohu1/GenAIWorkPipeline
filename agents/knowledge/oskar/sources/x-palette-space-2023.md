# @OskSta 2023-10-11 “Another take on a palette authoring tool”

- 链接：https://x.com/OskSta/status/1712088611934371876（用户 2026-10-06 提供；内置浏览器阅读正文，抽 6 帧看动图）
- 作者原话（摘要）：一个特征的“可能性空间”可以由任意个 0D 节点、1D 渐变和 2D 三角构成；四面体（3D）也想要，但工具会复杂很多。
- 逐帧取色（2026-10-06 第二次学习，40×40 降采样）：色场四角约为 左上灰绿 #5F8F6A、右上橙 #D5A157、左下蓝 #4B8598、右下玫瑰 #AE6874，中间是低饱和的插值色（如 #7D7F75）；左侧节点色块有浅粉 #EBB7AC、暖褐 #876C64。
- 动图所见：左侧每个颜色节点有 HSV 滑杆；右侧是由角点颜色张成的平面色场，内部被三角剖分，每个小三角是场里取到的一个颜色——同一套颜色在三角里连续变化、块面分明。

## 移植到本引擎（oskar/tint.py）

- 岩体 = 视频节点色的浅调，从山顶往下纵向铺色（橙 → 玫瑰 → 灰绿 → 蓝，按局部山顶高度归一）；横向只做很小的偏移（用户 2026-10-06 指出：视频是从山顶向下铺，是纵向的）；朝天面沿白色三角向米白靠；层纹明暗交替；逐面平涂不抖动。
- 草地 = 黄绿 / 橄榄 / 草绿 / 青绿色场。
- 结果逐面写进颜色属性（glTF COLOR_0），Blender 与 Godot 都按它着色；程序里 "tint": 0 关闭，0–2 调强度。

## 未移植

- 作者是交互式编辑色场；这里色场的角点由调色盘自动派生，节点不能手调。
- 3D 四面体空间、按材质特征分别建空间的完整工具没有做。
